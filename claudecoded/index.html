Altair 8800

A front panel you can actually operate. Behind it is a full Intel 8080 core running at 2 MHz; in front of it are two web components — <display-bit> for the lamps and <toggle-switch> for the paddles. There is not a <div> anywhere in it.

Driving it

    
    
      
  1. Flick ON, at the far left. The lamps come up showing the address register.
    2. 
      
  2. Set an address on the sixteen switches — up is a one, down is a zero — and flick EXAMINE. The address lamps echo it and the data lamps show what is in that byte.
    3. 
      
  3. Set a byte on the lower eight switches and flick DEPOSIT. DEPOSIT NEXT steps on a byte first, so you can pour a program in without touching the address switches again.
    4. 
      
  4. EXAMINE the start address, then flick RUN. STOP halts; SINGLE STEP advances one instruction at a time with the lamps frozen on the result.
    5. 
      
  5. RESET puts the program counter back to zero. PROTECT write-protects the 4K board holding the current address.
    6. 
    


    
Kill the Bit

    

      Load it, flick RUN, and a single bit walks through the upper address
      lamps. Flick the sense switch directly under the lit lamp to kill it —
      and flick it straight back down, because a switch left up only injects
      another bit. The eight sense switches are the upper half of the bank, the
      ones IN FF reads.
    


    
Why the lamps glow at half brightness

    

      Because the real ones did. A lamp on the address bus is lit only during
      the machine cycles that actually put its bit on the bus, thousands of
      times a second, and your eye averages the rest. This panel counts every
      bus cycle in a frame and sets each lamp's intensity to its duty cycle, so
      a fast loop smears the low address bits into a steady half-glow while the
      high bits step cleanly — exactly the texture you used to read a running
      program by.
    


    
The components


<display-bit label="A15"></display-bit>
  .on                 lit or dark
  .intensity          0..1, how brightly it burns
  label / color       attributes
  ::part(label|lamp)  styling hooks

<toggle-switch up="EXAMINE" down="EXAMINE NEXT" momentary></toggle-switch>
<toggle-switch label="15" value="down"></toggle-switch>
  .value              "up" | "center" | "down"
  .bit                1 when up, 0 when down
  momentary           spring return to centre
  "action" event      {detail: {direction}} on every flick
  "change" event      when a maintained switch settles somewhere new

    

      Both are standalone ES modules with no dependencies. A maintained switch
      reports itself to assistive technology as a switch; a momentary one gets
      a separate button per direction, so EXAMINE and
      EXAMINE NEXT are two distinct, individually named controls.
      Arrow keys flick a paddle up or down; space and enter work too.
    


    
No divs, anywhere

    

      Every box on this page — the case, the panel, each row, each octal group
      of lamps, the cards below — is an undefined custom element named for the
      thing it is: <altair-panel>,
      <lamp-bank>, <bit-group>,
      <switch-paddle>. They are never registered, so the
      browser leaves them as plain HTMLElements and they cost
      nothing. The one thing they do not inherit is a useful default: an
      unknown element with a hyphen in its name is display: inline,
      so every one of them is given a display of its own in
      panel.css. The buttons inside the switches are still real
      <button>s, because the accessibility tree needs them
      to be.
    


    
What this is not

    

      The machine underneath is the CPU, 64K of memory and the front panel, and
      nothing else: there is no serial board, no terminal and no disk
      controller, so it will not boot CP/M. It is the panel — the part you
      operated with your hands — rebuilt as web components. Inspired by the
      Altair simulator at s2js.com/altair/sim.html.
    


    

      The Altair 8800 was built by MITS in Albuquerque and announced on the
      January 1975 cover of Popular Electronics. This is a homage, not
      a product of theirs.
